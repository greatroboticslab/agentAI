Which numbers hold up

Every figure below was re-read from the results.csv the run itself wrote, not copied from an earlier table. Four numbers in the previously published tables did not survive that pass; they are corrected here and listed at the bottom.

Read the band before the number. Three evaluators are in play and they do not share a scale. The same YOLO11n checkpoint reads 0.8794 under the Ultralytics validator and 0.8554 under this project's own WBF matcher — an offset of 0.0239 from the measuring instrument alone. A number is only comparable to other numbers inside its own band.

Nothing here is a held-out test score. The 1,977-image set is passed to the trainer as its validation set, so it drives early stopping, selects the checkpoint, and is then the number reported. Every figure is a maximum over 21–100 evaluations taken on the set it is reported on. The size of that optimism is measured in the third column and ranges from +0.002 to +0.017.

Cause, isolated

Each round warm-started from the previous round's checkpoint. Four controls on round 15's exact dataset separate that from the training schedule. The two arms differ in exactly one thing: the initial weights.

The chain is the cause; the schedule is not. Arm B's best moment is epoch 1 — the checkpoint it walked in with. Twenty-nine further epochs of fully annealed training took it down to 0.529. Both arms are single runs; the effect would have to be six times smaller for the conclusion to change.

What the audit found

Each of these came out of the campaign's own logs and source, and each is checkable.

  • The training corpus never changed. From round 3 to round 15 the merge produced the same 24 datasets and the same 48,752 unique images, slug for slug. The apparent growth to 69,010 files was one staging directory that was never cleared between rounds.
  • Harvest returned nothing, eight rounds running, while reporting success each time — about 22 GPU-hours spent downloading and unpacking datasets that were then discarded. The step's own log configuration discarded every decision it made, so a 388 KB log contained no record of what it had rejected or why.
  • A Counter-Strike screenshot dataset entered the corpus. 4,014 images passed a fixed 0.50 quality threshold in round 9 and failed the same threshold in every other round, unchanged. The gate seeds each dataset's sample from its position in the registry listing, so adding any dataset re-rolls the verdict on every later one.
  • The holdout is not leaking, checked rather than assumed: 0 exact duplicates and 6 of 1,977 images (0.30%) within Hamming distance 6 of a training image — every one a consecutive frame from the same capture session. The split is random by image rather than grouped by session.
  • The layer built to notice all of this was itself mis-wired and returned silently for two weeks. The finding that surfaced the empty harvest came from a language model reading the evidence bundle, not from any deterministic check.

The scripted watchdog flags nothing, on any case. Its verdict files read "no signal fired" while the status fields report success — 149 times out of 149. That is the baseline this project's dashboard was for six months.

Model size is not the axis. Three open models reading the same artifacts all land between 0.70 and 0.80 recall. What separates them is the false-alarm rate — 0.636, 0.212, 0.152 — so the choice of model buys precision here, not detection. The 14B reaches its recall by flagging 21 of the 33 control cases, which is exactly what those controls exist to expose.

DeepSeek-V4-Flash is deliberately absent. Its 0.388 comes from the run withdrawn for context overflow, where a third of the prompts were refused and scored as misses. It is a floor for a different setup, not a comparable arm, and it is not shown beside these.

The supervision benchmark, before any model runs

A separate corpus of 162 real incidents from this project's own history, used to ask whether a language model reading the evidence catches failures the deterministic checks miss. These are properties of the corpus itself — they bound every number it will ever produce, and they were fixed before any model was run.

A rules-only baseline cannot exceed 0.559 detection recall here. That is arithmetic, not a measurement. Any “the model beats the rules by X” figure computed across all 127 incidents is partly reporting this ceiling — so the fair contest is the 71 reachable ones, and the 56 unreachable ones are where a model can contribute something a rule cannot by construction. Both belong on the slide, never one average.

No score from this benchmark is quotable yet. Its one run was withdrawn twice — the scripted baseline was undecidable on every case, a third of the prompts overran the context window and were scored as misses, and the corpus was re-frozen afterwards. A rerun has not been submitted. What is reportable today is the corpus and its limits, which is what this section is.

Numbers that must never be quoted bare

Each of these appears in an earlier table or document in a form the artifacts do not support.

0.9033
The best of four runs, not a seed mean. Only one of the four crossed 0.90, and RF-DETR's trainer accepts no seed — its --seed flag is a run label. Quote the four runs individually or not at all.
0.8974 ± 0.0040
Published as “n = 4 seeds”. It is 4 unseeded runs across 2 epoch budgets and 3 configurations; the spread is GPU non-determinism plus epoch budget, not seed noise. Also a different evaluator from every other number here.
0.907
Never measured. It is 0.8830 plus an evaluator offset observed once, on one checkpoint, without test-time augmentation, assumed to compose. It does not belong on a slide.
0.8554
The same checkpoint that reads 0.8794 under the Ultralytics validator. Quoting it as “the model's score” understates it by 0.0239.
“sealed”
The 1,977-image set has been the selection signal since 2026-03-15 — across every architecture comparison, every threshold sweep and all fifteen rounds. It is a validation set. Call it one.

What is still missing

  • A real test split. The fix needs a three-way split and 80–120 GPU-hours of retraining. Not attempted before the deadline; the optimism is measured and disclosed instead.
  • Seeds on the control arms. A and B are single runs. Two more seeds of arm A would turn the headline +0.0287 into a proper interval.
  • A second evaluation set. Every number on this page comes from one dataset. A second human-labelled cotton-weed set, scored exactly once with the models fixed in advance, is the strongest thing that could still be added.
  • Mamba-YOLO-T has one source. Its three values exist only in summary files, with no per-epoch curve behind them, unlike every other row.
